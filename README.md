# Sistema de Gestão de Produtos e Vendas

Projeto desenvolvido em Python para gerenciar produtos, controlar estoques e registrar vendas utilizando um banco de dados SQLite.

## Funcionalidades

* Cadastro de produtos.
* Listagem de produtos cadastrados.
* Busca de produtos.
* Edição de preços e quantidades.
* Exclusão de produtos.
* Registro de vendas.
* Atualização automática do estoque após uma venda.
* Histórico de vendas.
* Relatórios de faturamento e produtos mais vendidos.

## Tecnologias utilizadas

* Python
* SQLite
* SQL

## Como executar

1. Instale o Python.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto no PyCharm.
4. Execute o arquivo `main.py`.

O banco de dados SQLite é utilizado para armazenar os produtos e o histórico de vendas.

## Objetivo

Este projeto foi desenvolvido para praticar programação em Python, operações com banco de dados, consultas SQL e organização da lógica de um sistema de gestão.
